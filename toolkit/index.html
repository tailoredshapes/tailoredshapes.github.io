The toolkit

Everything we build with, we built.

Three implementations of one model, four implementations of one log, and the tools that generate them. What's published is BSL 1.1 — free for non-production use, commercial licence for production. The cloud and database backends are commercial. merkql is public on purpose.

Service
the API layer

TypeScript · the original

meshql-ts

Schema-driven REST + GraphQL with Express, federation resolvers, four database backends. Where the model was proven.

Source →
Java 21 · enterprise

meshql-java

Jetty 12, virtual threads, PostgreSQL, MongoDB, SQLite, ksqlDB. The one to pick when your platform team already speaks JVM.

Source →
Rust · deploy anywhere

meshql-rs

A 3.8MB binary that boots fast enough for Lambda and small enough for the edge. Same model, same schemas.

Source →

We built the same thirteen-entity federated API in all three, against the same MongoDB. Under load they converge — the gap between them disappears behind a single database query. So the language question isn't “which is fastest”, it's “which does your team ship reliably in”. Answer that one and we'll use it.

Storage
the log

Rust · embedded log · open source

merkql

Kafka semantics on a merkle tree: topics, partitions, consumer groups and inclusion proofs, without the cluster. Single-writer by design, and it says so plainly when you outgrow it.

Source →
Rust · S3 Express One Zone · commercial

merk-aws

Concurrent producers serialise against S3 itself, so many Lambdas write one partition with nothing coordinating them — and nothing running between requests.

Rust · Azure append blobs · commercial

merk-azure

Native append blobs with server-enforced sealing. No Azure SDK — a handful of REST calls and a signer — so an Azure Functions cold start stays small.

Rust · PostgreSQL · commercial

merkpgql

The log in your database and in your transactions. An append shares a commit with the domain write that caused it — which is the outbox problem not existing, rather than being solved.

Tooling

CLI · code generation

Mesher

Point it at a legacy database, describe the domain, get a complete anti-corruption layer project: introspection, mapping, generation. Minutes, not months.

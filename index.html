The proof
one suite,
four backends

Portability you can run, not portability you're promised.

Anyone can write “pluggable backends” on a slide. The question worth asking a supplier is: how would we find out if it were untrue? Here is our answer — one event-log surface, four independent implementations, and a single suite that runs the same behavioural tests against every one of them on real infrastructure.

Records serialise to identical bytes and merkle roots agree at every size, so a proof issued by one backend verifies under another. Practically: when you migrate, you can check that the data that arrived is the data that left — rather than hoping.

Compiling the suite proves the API matches. Passing it proves the behaviour does. The suite is public — you can run it yourself, which is rather the point.
